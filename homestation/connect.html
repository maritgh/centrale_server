Live weergegevens van onze Home Stations

Weerkaart Station aanmelden Hoe verstuur ik data?

Meetgegevens versturen vanaf je ESP32

Jouw ESP32 stuurt temperatuur, luchtvochtigheid en windsnelheid naar de centrale server met een HTTP PUT-request.

Vul hieronder jouw Station ID en API-key in. Als je net een station hebt aangemaakt, worden deze automatisch ingevuld.

Gebruik een adres dat jouw ESP32 via WiFi kan bereiken. Voor een lokale server is dit het LAN-IP van je computer met poort 3000.

1. PUT-request

Jouw ESP32 verstuurt de meetgegevens naar: 



            

                Bij het request stuur je jouw API-key mee:
            


            


            

                De body van het request ziet er bijvoorbeeld zo uit:
            


            
{
  "temperature": 20.4,
  "humidity": 58,
  "windSpeed": 2.7
}



            
2. ESP32-code


            

                Voeg onderstaande functie toe aan je Arduino-project.
                Je ESP32 moet al verbonden zijn met WiFi.
            


            

            
Voor HTTPS: vervang de certificaat-placeholder in de code door het PEM-rootcertificaat van de server en synchroniseer de ESP32-klok via NTP voordat je data verstuurt.


            


            
3. Gebruik de functie


            

                Wanneer je jouw meetgegevens naar de server wilt sturen,
                kun je de functie aanroepen met jouw eigen sensorwaarden:
            


            
sendHomeStationData(
    temperature,
    humidity,
    windSpeed
);


            

                Hierbij is:
            


            
    
                
  • 
                    temperature =
                    temperatuur in °C
                
    • 

                
  • 
                    humidity =
                    luchtvochtigheid in %
                
    • 

                
  • 
                    windSpeed =
                    windsnelheid in m/s
                
    • 
            


            

                Je bepaalt zelf waar en hoe vaak je deze functie
                in jouw programma aanroept.
            


            

                Bij een succesvolle request geeft de server
                HTTP-code 200 terug.
