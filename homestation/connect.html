Meetgegevens versturen vanaf je ESP32

Jouw ESP32 stuurt temperatuur, luchtvochtigheid en windsnelheid via MQTT naar drie afzonderlijke topics.

Vul hieronder jouw Station ID en API-key in. Als je net een station hebt aangemaakt, worden deze automatisch ingevuld.

Gebruik een adres dat jouw ESP32 via WiFi kan bereiken. Voor een lokale broker is dit het LAN-IP van je computer met poort 1883. Gebruik mqtts:// voor TLS.

1. MQTT-topics

Publiceer één bericht per meetwaarde op het bijbehorende topic:


            
Elk bericht is JSON met jouw API-key en één numerieke waarde. Bijvoorbeeld voor temperatuur:

            

            
Publiceer zonder retain. De server bewaart de laatste waarde van elk topic.


            
2. ESP32-code


            

                Voeg onderstaande functie toe aan je Arduino-project.
                Installeer de Arduino-library PubSubClient van Nick O’Leary. Je ESP32 moet al verbonden zijn met WiFi.
            


            

            
Voor MQTT met TLS: vervang de certificaat-placeholder in de code door het PEM-rootcertificaat van de broker en synchroniseer de ESP32-klok via NTP voordat je data verstuurt.


            


            
3. Gebruik de functie


            

                Wanneer je jouw meetgegevens naar de server wilt sturen,
                kun je de functie aanroepen met jouw eigen sensorwaarden:
            


            
Roep setupHomeStationMqtt() aan in setup() en loopHomeStationMqtt() bij iedere loop(). Verstuur vervolgens periodiek je metingen:

            
sendHomeStationData(
    temperature,
    humidity,
    windSpeed
);
