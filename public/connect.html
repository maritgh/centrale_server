Aan de slag met MQTT

Verbind je ESP32

Jouw ESP32 stuurt temperatuur, luchtvochtigheid en windsnelheid via MQTT naar drie afzonderlijke topics. Via een eigen actuator-topic ontvangt je ESP32 ook opdrachten vanuit Mijn station.

Hieronder zie je alvast voorbeeldcode, ook zonder gegevens in te vullen. Vul jouw Station ID en API-key in en klik op Maak mijn code voor je eigen versie. Als je net een station hebt aangemaakt, worden deze automatisch ingevuld.

Gebruik het brokeradres dat jouw ESP32 kan bereiken. Voor een openbare broker gebruik je mqtts:// en poort 8883.

Maak eigen grootheden eerst aan in Mijn account. Vul de sleutels in, gescheiden door komma’s.

4. Een actuator aansturen

            
De code bevat al een MQTT-callback die JSON-opdrachten op het eigen actuator-topic verwerkt.
                Laat loopHomeStationMqtt() bij iedere loop() draaien, ook als je geen metingen verstuurt.
                De code abonneert opnieuw na een verbroken verbinding.

            
Het voorbeeld gebruikt een gewone digitale led. Zet actuatorLedPin op de GPIO van jouw led.
                Met de standaardwaarde -1 zie je opdrachten alleen in de seriële monitor.
                Schakelt jouw led in bij een laag signaal? Zet dan actuatorLedActiveLow op true.
                Voor een adresseerbare RGB-led of een andere actuator pas je handleHomeStationActuator() aan.

            
Open Mijn station, log in en stuur bij Actuator aansturen:

            
{"led":true}

            
Uitschakelen kan met:

            
{"led":false}

            
De opdrachten bevatten geen API-key. De server kiest het station via je ingelogde account.
                De ESP32 moet verbonden zijn op het moment van versturen; opdrachten worden niet bewaard.
